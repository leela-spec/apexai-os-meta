# OpenClaw Local Executor — Master Brief

The active mission is to install and validate one bounded local executor composed of OpenClaw and Qwen3-8B. APEX and project workflows retain planning, prompt, provider, evaluation, scheduling, and continuation authority.

Canonical authority, in order:

1. `FEE/OpenClaw Local Executor — Operator Decision Lock.md`
2. `FEE/OpenClaw Local Executor — Installation and Implementation Plan.md`
3. Current explicit operator instructions
4. Measured installation and verification evidence

The Local Executor may use only the roots, tools, commands, providers, Git permissions, success conditions, and stop conditions granted by a validated execution request. It must not become a separate FEE runtime, global queue, planner, evaluator, provider selector, or orchestration authority.

Installation begins with the standalone llama.cpp structured-tool-call baseline, continues through the pinned OpenClaw installation and standalone/in-process provider comparison, and ends only after the gated browser, script, Git, Cron, persistence, containment, and idempotency checks pass.
