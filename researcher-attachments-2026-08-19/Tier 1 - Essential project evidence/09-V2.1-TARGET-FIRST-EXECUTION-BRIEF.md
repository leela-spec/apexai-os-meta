# 10. QUALITY STANDARD FOR THE ACTUAL KNOWLEDGE PRODUCT

After the pipeline produces the artifacts, inspect the artifacts themselves.

A successful knowledge product should demonstrate:

- **coverage:** important ideas from early, middle, and late source regions survive into the knowledge artifact;
- **specificity:** the Macro/Meso/Micro content reflects the actual source rather than a generic template;
- **grounding:** factual/testable claims point to transcript evidence and exact quotes where required by the V2.1 evidence policy;
- **semantic usefulness:** the Macro explains what the source is substantially about; Meso modules group meaningful themes; Micro claims preserve useful atomic knowledge;
- **language fidelity:** German material remains coherent and semantically faithful rather than being degraded by an English-first extraction pattern;
- **relationship quality:** concepts/entities/claims are not merely generated for schema completion but add navigable knowledge value;
- **uncertainty fidelity:** uncertainty, opinion, prediction, and contradiction are not silently converted into facts;
- **non-boilerplate:** outputs from different sources are materially different because the sources are different;
- **operational completeness:** the production entrypoint can create the package without manual semantic authoring by the coding agent.

Use the existing human-gold/operator rubric and deterministic TTK rules where they help judge these qualities.

If the produced artifact is weak, improve the actual Map/Reduce prompts or runtime and rerun the affected output. Do not compensate for weak content by adding a stronger validator.
