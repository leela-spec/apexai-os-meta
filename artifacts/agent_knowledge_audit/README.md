## 1. Executive Summary & Ecosystem Overview

### 1.1 Context & Purpose
The APEX Operating System (`apexai-os-meta`) has undergone radical architectural transitions—shifting from a multi-agent continuous swarm runtime (OpenClaw Era 1) to an intermediate consolidation (2026-07-11 Fable Orchestrator Era 2), and finally into a deterministic, file-backed, single-engine WSL2 operating spine (Modern APEX OS Era 3).

During these rapid evolutions, hundreds of agent contracts, operational workflows, prompt templates, research corpora, and doctrine manifests were generated, migrated, pruned, or abandoned. This audit provides the **first complete, mathematically verified, 100% census of all agent knowledge assets across both the active Git repository and legacy preparation archives**.

- **Specific High-Value Lost Doctrine:**
  1. **Empirical Directive Ceilings by Model (Frontmatter & Section 7):**
     ```yaml
     directive_ceilings:
       gpt_4o:                      50   # exponential decay; F-10
       claude_3_7_sonnet_standard:  50   # linear decay; F-10
       claude_3_7_sonnet_reasoning: 80   # linear decay, reasoning tasks; F-10
       gemini_2_5_pro:             100   # threshold decay, cliff onset 150-250; F-10
       o3:                         100   # threshold decay, cliff onset 150-250; F-10
     ```
     *Operational Significance:* Mathematical proof of why agent system prompts break. When total imperative directives in an agent's context exceed these thresholds, LLMs experience steep compliance decay.
  2. **The 500-Token Primacy Rule (CD-01, AP-07):**
     - *Rule:* Place all critical-tier directives in the first 500 tokens of every file.
     - *Empirical Basis:* Directives placed past token 500 suffer a 30% to 50% drop in compliance due to the "lost-in-the-middle" positional attention attenuation. Compliance at tokens 0–500 is ~73% vs. <35% in mid-document bodies.
  3. **Modal Verb Ban (CD-04, DWR-01, AP-05):**
     - *Rule:* Start every directive with an imperative verb (`Return`, `Halt`, `Validate`, `Split`). Strictly prohibit modal hedging (`should`, `may`, `might`, `could`).
     - *Empirical Basis:* Models interpret modal verbs as optional suggestions rather than deterministic constraints, introducing probabilistic drift into governance loops.
  4. **Four-Way File Type Taxonomy with Rigid Token Budgets (Section 2):**
     - `system_prompt`: $\le$ 2,000 tokens, directive count $\le$ model ceiling.
     - `knowledge_base`: $\le$ 100,000 tokens, directive count = 0 (strictly factual lookup).
     - `workflow`: $\le$ 4,000 tokens, directive count $\le$ 15 (steps, preconditions, stop conditions).
     - `tool_definition`: $\le$ 1,000 tokens, directive count $\le$ 5 (schemas, error handling).
  5. **Minimal Viable File Test (MVT-01..04):**
     - A 4-step checklist to run before authorizing any prompt or instruction block for production.
