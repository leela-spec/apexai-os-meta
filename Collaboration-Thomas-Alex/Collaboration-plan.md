# Thomas and Alex collaboration plan

The goal is an online sales presentation of Thomas's AI business stack in late November 2026. The three use cases are already defined. Other task dates have not been specified.

## Tasks

- **Alex & Thomas — owner to confirm:** Create the goal for the online presentation in OpenProject.
- **Alex:** Build and run the three existing use cases using Thomas's infrastructure.
  - **Alex:** Run the use case for a self-employed person, such as a coach.
  - **Alex:** Run the use case for a society or association.
  - **Alex:** Run the use case for a small or medium-sized business.
- **Alex:** Deliver agent orchestration for the stack.
  - **Alex:** Include reasoning models and ranking systems.
  - **Alex:** Address the combination of orchestration teams, reasoning models, and task rating.
  - **Alex:** Deliver weekly orchestration.
- **Alex & Thomas — owner to confirm:** Deliver the agent directory.
- **Thomas:** Develop the business stack.
  - **Thomas:** Develop project management capabilities.
  - **Thomas:** Develop strategic management capabilities.
  - **Thomas:** Extend the stack for ERP and CRM.
  - **Thomas:** Create pricing for the stack.
- **Alex & Thomas — owner to confirm:** Find a solution for Steuer/tax.
- **Alex:** Connect Thomas with other people to help promote his stack.
- **Alex & Thomas:** Define how to become partners and founders in each other's GmbHs.
