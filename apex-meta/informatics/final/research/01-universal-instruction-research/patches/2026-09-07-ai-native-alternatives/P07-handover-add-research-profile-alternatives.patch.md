### Optional evidence-order comparison profile

The default execution profile in this handover is **AI-native-first**, but the earlier discipline-first style is retained as a deliberate comparator rather than erased.

**Profile A — AI-native-first (default candidate)**

```text
current OpenAI / ChatGPT / Codex guidance
  -> independent mature-agent convergence
  -> established external discipline
  -> local synthesis
```

**Profile B — discipline-first comparator**

```text
established external discipline / vocabulary
  -> mature agent implementations
  -> current AI-specific adaptation
  -> local synthesis
```

Use Profile B only as an explicit comparison when there is reason to test whether durable external methodology exposes material requirements or failure modes missed by Profile A. If both profiles are tested, keep their evidence paths and resulting wording candidates separate until comparison; do not silently blend them.

The comparison must judge observable output quality, target adherence, omissions, over-triggering, autonomy, context/token cost, and cross-agent portability. Neither profile wins by authority, age, vendor status, or terminology alone.
