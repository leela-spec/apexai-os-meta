# RP-04 - Established name for the communication register

**Verdict (confidence: high on the colour-reference match; medium that it is the exact phrase recalled; high that no single *writing standard* reviewed covers the whole brief):** The strongest match for the recalled **blue-coded style is `Cool Blue`, an energy in the Insights Discovery four-colour personality/communication model**. Its publisher describes Cool Blue as analytical, objective, detached, precise, questioning and formal - an unusually close match to the operator's recollection and the existing repository discussion. **It is not a standard AI output-style mode, nor a scientific-writing standard.** For executable agent instruction, use a short *descriptive* clause such as **'evidence-led, analytical technical register'**, optionally annotated as **'Cool Blue-inspired'**. Do not assume the words 'Cool Blue' alone will reliably instruct a different model.

## Colour-model verdict - specific answer

- **Yes, a current colour-coded interpersonal/communication framework exists:** **Insights Discovery - Cool Blue**. Its official model page remains available and identifies the term as one of four colour energies. This is a **first-party definition**, not independent empirical proof that prompts using 'Cool Blue' produce reliably better answers.
- **No verified industry-wide colour-coded AI text-style standard was found** in the AI vendor documentation checked. Neither ChatGPT's professional tone nor vendor general prompting guidance defines 'blue mode' as a shared standard.
- **This is not necessarily the only 'blue' personality category.** Different colour frameworks map colours differently, so the unqualified phrase 'blue personality' is ambiguous. Cite the **Insights Discovery** brand if using the label.
- The local [`08-discussion-and-open-threads.md`](08-discussion-and-open-threads.md) already proposed Cool Blue; **this research confirms that published framework matches the recollection** but cannot confirm what the operator personally saw. No operator confirmation was solicited, per handover.

## Suggested rule, usable verbatim (19 words)

> Use an evidence-led, Cool Blue-inspired technical register: precise, neutral, analytical, concise, and willing to challenge unsupported claims.

**For maximum cross-agent portability**, omit the brand-derived phrase and keep: **'Use an evidence-led technical register: precise, neutral, analytical, concise, and willing to challenge unsupported claims.'** The latter is not a formally named standard; it conveys the intended behavior directly.

**Important qualifier:** The candidate's `<communication>` currently says **'No hedging'**. A factual scientific register should distinguish **unsupported hedging** from **warranted uncertainty**. Unqualified 'no hedging' could conflict with the `<ground>` instruction to report absent or weak evidence. A precise alternative would be **'State uncertainty when evidence warrants it; avoid empty hedges.'** This is a drafting recommendation, not a change to the live candidate.

## Strongest case against the verdict

Insights Discovery **is a personality instrument and interpersonal communication scheme**, not a scientific writing standard. Simply naming 'Cool Blue' can import unrequested traits (introverted communication, lengthy analysis, risk aversion, rigid process), exactly the kind of overhead this contract tries to reduce. The historical colour memory may instead have been a different diagram. Moreover, the user wants rational rigor **and high speed/low filler**; a standard called 'Cool Blue' does not encode these operational constraints. **Therefore the descriptive existing clause is safer than replacing it with a label alone.** If token compression is the purpose, a tiny rule showing intended behavior is more portable than an ambiguous branded shorthand.

## What I could not find

- An official or independently measured **cross-provider AI 'blue communication mode' standard**, including evidence that one label works across coding agents.
- A single formal scientific/technical register term that **simultaneously** mandates brevity, neutral affect, adversarial scrutiny, zero flattery and strict evidence citation.
- A controlled A/B experiment showing that writing 'Cool Blue' instead of a six-adjective description yields equal or superior agent output at fewer tokens.
- Independent evidence of the operator's original exposure to the colour; existing repo discussion contains a **hypothesis**, not personal confirmation.

## Consequence for the contract

- **`<communication>`:** do not replace the descriptive clause with **'Cool Blue' alone**. The framework resolves the colour recollection credibly; retain practical behavioral adjectives in a short phrase.
- **`<ground>`:** evidence first and justified uncertainty should not be sacrificed for an impression of tough confidence.
- **`DEC-17` / `RP-09`:** a branded style name is **not** a proven token-efficiency lever. Token count and resulting behavior must both be measured.
- **No edits made** to repository candidate or live rules.
