## 2. Five Visualization Candidates

1. `01-project-week-matrix.html` — **Project × Week Matrix** (Single cross-matrix grid)
2. `02-two-tier-ribbon-matrix.html` — **Two-Tier Ribbon + Matrix** (Compact capacity ribbon + trajectory matrix)
3. `03-week-strip-project-arcs.html` — **Week Strip + Project Arcs** (Rhythm strip + horizontal project steppers)
4. `04-day-agenda-cards.html` — **Day Agenda Cards** (Five equal-weight day cards)
5. `05-strategic-swimlane-critical-path.html` — **Strategic Swimlane / Critical Path** (Project swimlanes + critical path cues)

## 3. Shared Dataset

All five candidates consume the exact same shared dataset defined in `prototype-data.js` (derived from confirmed 2026-W34 baseline). Each prototype includes an interactive toggle to compare the **Normal W34** baseline against a **Stress Week** (meeting-heavy/compressed) scenario.

No production files, skills, templates, or contracts were modified. These prototypes are visual evaluation artifacts created strictly within the research workspace.
