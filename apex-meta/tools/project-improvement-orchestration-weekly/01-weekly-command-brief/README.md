# Module 01 — Weekly Command Brief

## Purpose

Land the intended week-level operator interaction and output in the real PrecapWeek production path.

## Expected function

Weekly planning is an **iterative operator + AI planning conversation** about the coming week, not a project-status dump. It should use confirmed project reality, relevant recent outcomes, capacity/calendar context and operator intent to decide useful weekly outcomes and unresolved choices.

## Expected output

A readable **Weekly Command Brief** answering:

- what should this week accomplish;
- why these outcomes matter now;
- what each active project is trying to achieve;
- important blockers/dependencies/decisions;
- expected outputs/success evidence;
- optional day/sequence seeds when useful;
- what requires operator approval or correction.

## Known current defect

The current W34 weekly packet is schema/envelope-heavy and contains repeated metadata and provisional numeric mappings. The recovered J02 human-facing design exists but was not made the active runtime output.

## Module work

A fresh module chat should discuss the detailed weekly Q&A semantics and artifact shape with the operator, then update the real PrecapWeek skill/agent/template/contracts to produce it within the interfaces established by Module 00.

## Completion

Production implementation -> Master integration PASS -> fresh W34 weekly test -> operator acceptance.
