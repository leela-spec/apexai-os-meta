# Module 02 — PreCap Next Day Brief

## Purpose

Land the day-level planning interaction and compact overview that translates the approved week plus current reality into the next execution day.

## Expected function

The day brief is the operator's overview, not the detailed flow workspace. It should explain what tomorrow is for, which flows are represented, why they are selected, expected flow outcomes, short three-sprint summaries and material review questions.

## Expected output

One readable Next Day Brief containing:

- day direction;
- represented flows;
- why each flow is today;
- weekly link/context;
- expected flow result;
- compact S1/S2/S3 summary;
- flow-card link;
- cross-flow order/dependency when relevant;
- end-of-day target;
- only material review flags.

## Known current defect

The W34 next-day plan duplicates substantial flow metadata and feeds large schema-first per-flow packets/prompt packs.

## Module work

Fresh module chat defines exact daily Q&A and overview behavior, then integrates the result into the active PrecapNextDay production path while respecting Module 00 interfaces and avoiding duplication with Flow Execution Cards.

## Completion

Production implementation -> Master integration PASS -> fresh W34 next-day test -> operator acceptance.
