## 1. The Three Structural Archetypes

Every multi-variation project or webpage suite MUST implement at least two (ideally three) mutually exclusive structural archetypes:

### Archetype 1: Asymmetric Editorial (Contemplative / Philosophical)
* **DOM Topology:** Multi-column asymmetric flow (65/35 offset), generous vertical whitespace, inline pull-quotes, marginalia footnotes.
* **Component Kit:** Typographic essay blocks, audio player bars with timestamps, collapsible footnote drawers, text-only signup dialogs.
* **Target Domains:** ACIM Secular, Meditation Whitepapers, Philosophical Inquiries.

### Archetype 2: Somatic Bento Grid (High-Energy / Movement / Physical)
* **DOM Topology:** 12-column Bento Grid with asymmetric card spans (4x2 hero, 2x1 metric widgets, 2x2 media tiles).
* **Component Kit:** Video player hero, interactive frequency/rhythm soundboards, live countdown tiles, visual workshop seat pickers.
* **Target Domains:** Dance Fusion, SuperHeroKids Physical Workshops, Somatic Coaching.

### Archetype 3: High-Density Systems Matrix (Governance / Algorithmic)
* **DOM Topology:** 3-pane fixed cockpit (Sidebar directory + Tabular data grid + Real-time inspector sidebar).
* **Component Kit:** Monospace data tables, filterable shift matrices, fairness audit scorecards, downloadable JSON schema anchors.
* **Target Domains:** Lika Shift Planning OS, IPOS Macro Dashboard, Weekly Orchestration Telemetry.
