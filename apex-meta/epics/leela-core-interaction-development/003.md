# Promote bounded cluster to primary Skill Tree navigation

## Acceptance Criteria

- Home Skill Tree affordance reaches bounded spatial Skill Tree.
- Placeholder `/st` behavior is removed from the integrated Home path.
- Discover Learn reaches the same primary bounded spatial Skill Tree.
- Router semantics do not create competing primary Skill Tree destinations.
- Legacy `/skill-tree` is explicitly retained as accessibility/debug fallback or retired based on runtime evidence.
- Primary path does not silently depend on obsolete mastery/stats mock semantics.

## Definition of Done

- Home and Discover share one primary Skill Tree surface.
- Legacy surface status is explicit and documented.
