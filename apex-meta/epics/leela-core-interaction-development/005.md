# Quarantine fake and legacy scope-resolution state from the integrated path

## Acceptance Criteria

- Null/no-scope is valid clean initial state for integrated Home path.
- Hard-coded German Music `g_scope` and `g_resolvedScope` are not treated as current user/resolution truth.
- SCRPickerScope no longer acts as authoritative resolver over `GS_SkillTree.treeModel` for integrated path.
- Legacy visible-chunk-descendants resolution is not promoted as final Algorithm semantics.
- Legacy GS_SkillTree/MockScopeSelection state is not copied into bounded-cluster architecture.
- Fixture/demo defaults remain explicitly test/demo only.

## Definition of Done

- Integrated Home -> Skill Tree flow cannot succeed using fabricated scope or legacy resolver truth.
- Boundary between confirmed Skill Tree scope and downstream resolution is explicit.
