# Verify Home runtime against current Home screen contract

## Acceptance Criteria

- Run SCR_Home_Today in the supported local/simulator environment.
- Check visible layout/responsive behavior, orb/feature preview, feature tabs, TP/XP/BP presentation, upcoming events, recommendation carousel, scope/duration controls, Pre-Run transition, Sid/search/settings, and loading/error/empty behavior.
- Compare runtime observations to `docs/ssot/screens/home-today.md`.
- Record existing card/layout debt explicitly.

## Definition of Done

- Evidence-backed Home runtime conformance report exists.
- Every observed gap is classified as keep, repair, mock/prototype debt, obsolete, or deferred.
