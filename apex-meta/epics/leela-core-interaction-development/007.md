# Build Home request adapter into frozen resolution context

## Acceptance Criteria

- Consume confirmed ScopeSelection without mutation or widening.
- Represent Home duration/mode narrowing as request input.
- Current Rhythm snapshot/revision enters context through owner contract.
- Path snapshot is included only according to reconciled contract.
- Preserve allowed TemplateVersion identity.
- ResolutionRequest/ResolutionContext has deterministic fingerprint.
- Home remains requester/presenter and performs no eligibility, scoring, ranking, or concrete Chunk binding.

## Definition of Done

- Home can request one fresh frozen resolution context from current owner inputs.
- Legacy `GS_Spark.resolveSelection(treeModel)` is unnecessary for this path.
