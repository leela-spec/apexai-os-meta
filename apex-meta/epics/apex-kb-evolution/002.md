# Build operator-value and retrieval benchmark for ApexKB

## Acceptance Criteria

- Create predefined high-value query set from real intended use cases.
- Rubric covers correctness, completeness, reasoning, provenance, uncertainty, and practical usefulness.
- Define retrieval relevance measures.
- Test raw-source reopen behavior.
- Measure token/context cost against raw corpus reading.
- Include changed/added/deleted/superseded source update cases.
- Separate deterministic completion from semantic usefulness.

## Definition of Done

- Current ApexKB has a measured value baseline rather than only structural test counts.
