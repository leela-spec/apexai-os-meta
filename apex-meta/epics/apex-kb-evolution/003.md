# Evaluate cheapest credible ApexKB upgrade path

## Acceptance Criteria

- Rank improvements by measured benchmark impact and implementation cost.
- Consider lexical improvements, hybrid/vector retrieval, reranking, query planning, and evidence-packet generation only where justified.
- Evaluate semantic acceptance, future-agent integration, lifecycle/operator UX simplification, and update/drift reliability.
- Preserve local/private operation options.
- Do not add architecture solely because fashionable.

## Definition of Done

- Bounded upgrade candidate and expected benchmark gains are explicit.
