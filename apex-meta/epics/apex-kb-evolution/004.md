# Evaluate current ApexKB alternatives and hybrid options

## Acceptance Criteria

- Use current primary documentation/code for every candidate.
- Evaluate local indexed LLM-wiki projects individually and re-verify prior competitors.
- Add alternatives only when matching operator goals.
- Score source preservation, retrieval/answer quality, updates, privacy, local operation, integration simplicity, maintenance cost, and migration cost.
- Explicitly evaluate hybrid retention of Apex deterministic custody/audit around another engine.
- Do not treat marketing claims as verified capabilities.

## Definition of Done

- Decision matrix compares keep/upgrade, replace, and hybrid paths on current evidence.
