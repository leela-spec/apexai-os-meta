# Define investment alert contract and signal thresholds

## Acceptance Criteria

- Define alert categories and source inputs.
- Define meaningful-change/signal conditions.
- Define deduplication/cooldown behavior.
- No-signal behavior suppresses notification.
- Delivery target is explicit.
- Alert payload distinguishes observed fact from interpretation.

## Definition of Done

- One implementation-ready low-noise alert contract exists.
