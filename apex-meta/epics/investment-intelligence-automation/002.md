# Configure and test OpenClaw Cron video-search job

## Acceptance Criteria

- Use existing Cron scheduler.
- Job prompt is self-contained.
- One manual immediate test succeeds before relying on schedule.
- Duplicate/no-result behavior is bounded.
- Results land in selected output/delivery surface.
- Job can be listed, paused, edited, and removed through existing Cron controls.

## Definition of Done

- One operational tested scheduled video-discovery job exists.
