# Define portfolio and trading decision-feedback record

## Acceptance Criteria

- Separate decision-time evidence, thesis, expected outcome, risk, and later outcome.
- Position/trade identifiers can be referenced without autonomous brokerage access.
- Feedback horizons/review triggers are explicit.
- Later evaluation distinguishes decision quality from outcome luck where possible.
- Preserve source/evidence links.

## Definition of Done

- One reusable decision-feedback schema/process exists.
