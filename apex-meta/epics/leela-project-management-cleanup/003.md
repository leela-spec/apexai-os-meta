# Retire or annotate stale Spatial Opus control instructions

## Acceptance Criteria

- Stale Nowa constraints are not presented as current rules.
- Stale OD-1 through OD-6 status is not presented as current decision truth.
- Old files carry clear superseded/historical metadata or move to explicit archive location.
- Preserve historical rationale.
- Still-valid workflow rules point to current authority instead of restating it.

## Definition of Done

- Old Spatial Opus handovers cannot be mistaken for current restart authority.
