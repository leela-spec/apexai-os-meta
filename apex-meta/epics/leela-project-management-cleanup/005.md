## Acceptance Criteria

- Apex task represents project outcome/state.
- Application Micro packet represents one runtime executable increment.
- Mapping between active Micro packet and parent Apex task is explicit when applicable.
- Neither layer duplicates semantic product truth.
- Micro completion can feed confirmed Session progress without turning STATE.md into second project registry.

- Project management and runtime execution routing have documented one-way relationship.
