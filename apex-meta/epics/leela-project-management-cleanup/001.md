# Inventory and classify Leela project-control artifacts

## Acceptance Criteria

- Inventory project-control artifacts across `leela-spec/leela` and `Leela-Cloud-2026`.
- Classify each active/current/historical/superseded/duplicate/source-evidence-only.
- Record exact authority relation and superseding pointer where known.
- Do not mark product/research artifacts deletable merely because old.
- Capture known stale constraints in SpatialOpus handovers.

## Definition of Done

- Machine-readable project-control inventory exists.
- Every active-looking control artifact has explicit currentness status.
