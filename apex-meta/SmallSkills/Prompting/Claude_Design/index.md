# Claude Design — Prompting Skill Bundle

* [Design System Lock](design-system-lock.md) - Front-load brand tokens and reference screens before requesting any feature.
* [Anti-Slop Constraints](anti-slop-constraints.md) - Name and explicitly ban the generic-AI-aesthetic fingerprint.
* [Context Persistence](context-persistence.md) - Stop later edits from silently erasing earlier locked decisions.
* [Iteration Workflow](iteration-workflow.md) - Comment mechanics, live sessions, agent-mode vs. manual work.
* [Manual Editing Modes](manual-editing-modes.md) - Edit Mode, Tweaks panel, and Draw mode — fixing things yourself without prompting.
* [Known Issues and Quota](known-issues-and-quota.md) - Documented bugs and token-burn patterns to plan around.
* [Garment App Prompting](garment-app-prompting.md) - Applying all of the above to a clothing-design app UI specifically.

# Scope

This bundle targets **Claude Design** (Anthropic's standalone visual/prototyping product) specifically — not generic Claude chat prompting or Claude Code. Each concept file is independently loadable; load only what the current task needs.
