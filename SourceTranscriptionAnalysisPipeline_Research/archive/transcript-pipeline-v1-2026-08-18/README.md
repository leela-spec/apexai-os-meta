## Original Purpose of V1
The original V1 transcript-to-knowledge pipeline aimed to construct a minimal direct-CLI-based semantic worker pipeline using Claude Code CLI to parse, Map, and Reduce transcripts into grounded knowledge. However, the V1 recommendation over-corrected by excluding key reusable components from the primary architecture. The subsequent V2.1 design replaces these conclusions with a unified, benchmark-driven component reuse strategy.
